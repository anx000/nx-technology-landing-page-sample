## Getting started

1. Open the project in a browser:
   - Double-click `index.html`, or
   - Serve the folder with any static server (e.g., VS Code Live Server).
2. Ensure internet connectivity for Google Fonts.

## Features

- Animated hero with floating orbs and device card.
- IntersectionObserver-powered section reveals.
- Responsive navigation with mobile toggle.
- Detailed sections for services, process, work, testimonials, CTA, and contact form.

## Customization tips

- Update copy directly in `index.html`.
- Adjust colors, layout, or animations inside `css/style.css`.
- Replace placeholder project/testimonial info with real data.
